# QuizVideo

Free quiz video maker for TikTok, Reels, and Shorts: https://quizvideo.app

Everything renders in the browser (Canvas, WebCodecs, Mediabunny). Nothing is uploaded and there is no server.

- Formats: Guess the Country (outlines), Guess the Flag, Guess the Capital, Would You Rather, Trivia
- Exports: 1080x1920 MP4 and PNG slide sets for photo carousels
- Data: Natural Earth (public domain), Wikidata (CC0), flag-icons (MIT). See LICENSES.txt.
